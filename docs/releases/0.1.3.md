# Out Loud 0.1.3

CurseForge release type: Release. Use the same changelog for Forever and Retail.

## Changelog

- Voice selection dropdowns now list voices alphabetically, with "Not set" remaining first.
- Added a 30-second timeout when TTS playback does not start. Narration stops and the Talking Head closes instead of leaving the loading spinner running indefinitely.
- The timeout message suggests trying again and checking your TTS engine if the problem persists.

## Verification

Source review and the package builder's integrity and reproducibility checks are
separate from in-game verification. Timeout, first-playback cancellation, STOP,
request replacement, and normal playback still require in-game verification on
Forever and Retail. No standalone tests were requested or run for this release.
